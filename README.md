# Superstore Sales Dashboard

End-to-end Data Analytics project built using Excel, Power Query, MySQL, and Power BI.

## Project Overview
This project covers the complete data analytics workflow — from cleaning a dirty retail dataset to building an interactive executive dashboard.

## What I Did
- Cleaned a messy Superstore dataset in Power Query (handled missing values, duplicates, typos, invalid dates, and junk rows)
- Performed exploratory analysis using MySQL
- Created a professional Power BI dashboard with:
  - KPI cards (Total Sales, Profit, Margin, Orders, Average Order Value)
  - Year-over-Year Growth measures
  - Date table for time intelligence
  - Interactive slicers (Region, Category, Segment, Year)
  - Multiple visuals (Monthly trend, Region, Category, Segment)

## Key Insights
- Office Supplies and Technology are the top-performing categories
- High discount levels negatively impact profitability
- Significant performance differences exist across regions
- 2022 showed strong profit growth despite slower sales growth

## Tools Used
- Microsoft Excel & Power Query
- MySQL
- Power BI
- DAX
